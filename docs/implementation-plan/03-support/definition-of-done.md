# Definition of Done

每个任务/PR 关闭前逐项确认。

## 需求与范围

- [ ] PR/任务列出对应 requirement ID 和阶段任务 ID。
- [ ] 只实现批准的 P0/P1 范围；非目标未偷偷进入模型或权限。
- [ ] 原型冲突按现有裁决处理；新裁决已记录。

## 实现

- [ ] 依赖方向符合架构，View 不直接做网络/文件/系统调用。
- [ ] 并发有明确 owner、取消、互斥和 actor 隔离。
- [ ] 错误不被静默吞掉；用户看到原因和恢复动作。
- [ ] 持久化、文件与 current 标记保持事务一致。
- [ ] 没有 force unwrap 或 unchecked Sendable 掩盖不变量。
- [ ] 没有不必要第三方依赖。

## UI

- [ ] 正常、加载、空、离线、错误、禁用、警告、缺配置按适用范围覆盖。
- [ ] 键盘、VoiceOver、focus、高对比、减少透明度/动态效果已检查。
- [ ] 文案统一、无空按钮、无假数据冒充生产内容。
- [ ] 窗口宽度和长内容滚动符合设计验收。

## 安全与 macOS

- [ ] URL/日志脱敏；不记录二进制、密钥或用户隐私。
- [ ] 删除前验证路径在应用管理目录内。
- [ ] entitlement/Info.plist/signing/bundle ID 若变化已单独说明并获批准。
- [ ] 登录项、Menu Bar、壁纸或 Finder 集成有真机验证计划/结果。

## 测试与验证

- [ ] 新行为有确定性测试；时间不使用任意 sleep。
- [ ] 先运行最窄测试，再运行相关 suite。
- [ ] 主 macOS scheme 实际 build；未运行项明确说明。
- [ ] `git diff --check` 通过，最终 diff 已审阅。
- [ ] 未修改无关文件、未重格式化无关代码。

## 文档

- [ ] 追踪矩阵状态/证据更新。
- [ ] 迁移、权限、已知限制和人工步骤已记录。
- [ ] 命令及结果真实，不把“计划运行”写成“已通过”。
